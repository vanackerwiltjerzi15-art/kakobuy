# Kakobuy SEO Blog

A static SEO blog website built with VitePress.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Local development
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
kakobuy/
├── .vitepress/       # Configuration files
├── posts/            # Blog posts
├── public/           # Static assets
├── index.md          # Homepage
└── package.json      # Project config
```

## 📝 Add New Post

Create a new folder and `index.md` file in the `posts/` directory.

## 🌐 Deployment

Push to GitHub, and Cloudflare Pages will auto-deploy.

**Website**: https://kakobuy-7zh.pages.dev
