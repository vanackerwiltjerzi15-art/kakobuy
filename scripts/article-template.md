## 使用步骤

1. **复制模板**：将上方模板内容复制到新文件
2. **替换变量**：全局替换所有 `{{xxx}}` 占位符
3. **保存文件**：存为 `posts/{{系列关键词}}-style/index.md`
4. **添加封面图**：在同目录下放置 `mens-fashion-guide.png`
5. **更新导航**：在 `.vitepress/theme/PostsIndex.vue` 的 `CATEGORIES` 数组中添加新标签
6. **推送代码**：`git add . && git commit -m "Add: new {{系列关键词}} {{文章关键词}} guide" && git push origin master`
